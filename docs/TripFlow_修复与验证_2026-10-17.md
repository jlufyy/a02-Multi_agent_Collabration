| 问题 | 本次结果 |
|---|---|
| TF-01 保存覆盖已解析地点 | 正式计划保留服务端 resolved requirements；原始输入/对话/草稿单独保存。落地和提交校验顶层需求投影与任务绑定。补充刷新、提交、撤销和重做回归。 |
| TF-02 长路线跨日崩溃 | 排程不再把超窗活动移到错误日期。候选保留真实路线，由 A5 报告交通/窗口冲突，生成流程最多 3 轮删减可选活动；必去、锁定、已预约和固定条件不放宽。超出行程日期的固定安排返回 INFEASIBLE。 |
| TF-03 附近加入使用 UTC | 共享序列化按同一时刻转换为 +08:00，正确处理日期进位；空日按实际 dayIndex 构造日期；前端提交前校验格式和跨日，后端保留校验。 |
| TF-04 / TF-05 定位重复与低精度驻留 | 浏览器通过适配层复用根目录 ESM 引擎。512 条有界样本去重、严格递增采样时刻、低精度/隐藏/跳点/长间隔中断候选。旧本地状态不沿用未证明的驻留计数。活动地点/日期变化使旧地理进度失效，重叠围栏只累计一个到达。 |
| TF-06 过期提醒 | 排队和已显示卡片均核对 trip、revision、REAL/DEMO、demoRunId、活动、意图、arrivalId、当前定位新鲜度及队列时效。普通卡片在离开或位置不确定后失效；旧版本风险卡也失效。 |
| TF-07 地图 | 当前本机已有独立 JS Key，浏览器底图和真实 POI 标记已成功。增加 20 秒加载超时与重试。未复制后端 Web Service Key；未编造路线几何。生产域名、安全配置和 HTTPS 仍需部署环境验收。 |
| TF-08 时间小数 | 只在显示层向上取整，正确处理 59.9 分钟进位；底层供应商分钟精度保留。 |
| TF-09 内容超时 | A7 模型总时限覆盖重试/结构修复，限制 token，记录每次失败耗时。实测 DeepSeek 四类请求全部成功后，缺省 A7 明确改为 DeepSeek；显式 MODEL_ROUTES 优先。内容显示实际供应商和返回型号。AIPing 本次仍超时，未标为已恢复。 |
| TF-10 景区母子 POI | 仅在供应商返回可信 parent POI 字段时归组推荐候选，不按名称猜测。显式必去/固定/任务地点均保留，不自动删用户要求。缺少父子关系或套票范围时仍不能宣称时间/费用已去重核实。 |
| TF-11 多轮需求收集 | 默认入口为主助手对话和短摘要。A1 接收当前结构化草稿与对话，按 changedFields 合并，只更新相关字段并保留稳定身份/已匹配地点。最多两个关键问题，标记推断/建议；相对日期以北京时间为参照。可继续纠正，刷新恢复；完整表单作为高级编辑入口。 |
| TF-12 协作与确认简化 | 复用 A1–A7，不新增重叠职责。受影响路线局部更新，最终审核仍重新查询。进行中/已完成/锁定/预约/固定活动受保护。只有明确指定唯一地点、小幅时长、无连锁变化且完全核验通过时可直接提交；其余整批预览确认一次、整体撤销。未宣称已实现任意疲劳/迟到语义下的最优局部规划，也未证明调用量或时延提升。 |

另外修复了 AI 面板生成材料仅留在组件内的问题：材料写入本地工作区，刷新后可重新打开查看，标注旧版本；内容不能跨版本或工作区写入。服务设置明确区分“已配置”与实际请求成功。

最终审核发现实际路线变化时，保留用户整批操作并返回更新的候选摘要；旧候选不能提交。其它需重新检索的变化提供“按最新资料重新计算此修改”入口，避免卡死在禁用按钮。真实路况变化可能使原先候选不可行，不能为了完成提交而缩短交通时间。

- 修复后最终 HTTP 审计 27 条 PASS、0 FAIL；包括明确拒绝的非法请求和空内容列表处理，不把它们计为 27 个成功业务场景。
- 最终真实响应 21/21 通过前端运行时契约校验。纯步行规划返回合法候选，编辑提案、最终复核、周边搜索和缺省 A7 内容生成成功；没有使用原报告的备用计划覆盖首次失败。
- 独立 A7 实测：DeepSeek 讲解 9.12 秒、讲稿 11.15 秒、清单 13.18 秒、内容完善 6.58 秒，4/4 成功；AIPing 首次讲解 48.62 秒（包含地点核验）超时后停止剩余请求。样本过少，不提供可靠 p95 或长期失败率。
- 浏览器完整闭环通过：含天坛公园必去条件的计划保存后刷新，再将该站从 90 分钟改为 100 分钟，预览、最终复核、提交、撤销、重做和再次刷新均成功。单独真实周边地点 ADD 提案及最终复核也通过，证据为 `output/repair/nearby-add.json`。
- 浏览器实测了自然语言预填、一次改期和人数变更、刷新恢复、摘要确认、保存和真实地图标记。多站公交计划的最终核验发现实际交通变长，返回更新后不可行的摘要，原计划保留；没有强行提交。

本地证据保存在 `output/repair/`：`api-tests.xml`、`synthetic-probes.json`、`content-routes.json`、`nearby-add.json`、`browser-verification.json`、`browser-final.png`、`final-live/live-http.json`、`final-live/contract-samples.json`、`final-live/live-contracts.json`。该目录为本机输出，默认被 git 忽略；需要归档时应先检查内容并单独保存。

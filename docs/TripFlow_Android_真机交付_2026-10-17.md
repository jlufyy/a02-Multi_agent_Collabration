# TripFlow Android 真机交付记录

2026-10-17，个人签名版本 1.0.1（versionCode 2），包名 `cn.tripflow.app`，ARM64，最低 Android 8.0。已使用 `adb install --no-streaming -r` 覆盖安装到用户连接的华为 LNA-AL00（Android 12 / API 31），最终冷启动成功。覆盖安装未卸载应用、未清除应用数据；更新前读取到 3 条本地行程记录，正式版关闭 WebView 调试后未再次读取私有数据库。

## 本次行为

- 原 React 页面与原 Python FastAPI 后端通过 Chaquopy 在手机内运行，固定本地地址 `127.0.0.1:18761`。正常使用不依赖电脑服务或 USB 反向代理；地图、AI、搜索仍需要联网。
- 使用本机 ENV 配置生成私人运行包；源码仓库排除 ENV、APK、签名和生成资源。签名放在本机 `android/.local/`，后续更新须保留。
- 餐饮偏好不再强制用户在出发前选具体店。行程页的“找美食”可以围绕当前位置或明确的行程地点，按口味、半径、步行时间、人均参考预算查询。
- 应用内的 AgentRunner 执行 **A2 餐馆检索 → A3 真实步行路线 → A5 条件核验 → A2 评价资料搜索 → A7 来源展示**。每一步保留契约与进度事件；不为每个步骤增加大模型调用。
- 展示高德评分、人均参考消费、具体分店地址、参考点与餐馆地图、实际步行路线。添加餐馆走既有预览与核验流程，确认前不修改正式行程。
- 公开点评或探店摘要链接原文并标注查询时间，不能确认同城同店的内容不展示；未提供平台完整评论 API，不虚构用户、评论数或到店经历。
- 增加 Android 中文 TTS 适配、前台定位授权、返回键处理和页面地址恢复。未增加后台定位服务。
